Em transformar dados abrimos o editor do power query que é uma ferramenta de ETL (Extração, Transformação e Carga) criada pela Microsoft.
Ele serve para conectar a diferentes fontes de dados, limpar, organizar e automatizar o tratamento de informações antes de levá-las para análise em programas
como o Microsoft Excel ou o Power BI

Dentro dele podemos fazer: 
- Agrupamentos 
- Usar a Primeira linha como cabeçalho 
- Transposição
- Podemos verificar e modificar o tipo de dado  
- Dividir Colunas 
- Fundir Consultas
- Aplicar Formatação 
- Extração de dados 
- Analisar dados 
- Calcular Estatisticas 
- Invocar Função Personalizada 
- Coluna Personalizada
- Coluna Condicional 

Além disso podemos fazer integrações com: 
- Script R 
- Script Py(Python) 

OBS: O Power Bi não é uma ferramenta para ciencia de dados, ele é uma ferramenta para analise de dados 
porém nada pode impedir que usemos ele duranto o processo da ciencia de dados para tarefas especificas. 
---

Em Exibição podemos olhar a distribuição de coluna os perfils dela, mostrar ou não os espaçõs em branco
verificar qualidade da coluna e ainda temos o editor avançado que é quando editamos a linguagem M 
uma linguagem na qual trabalha por trá do PowerBI 
---

Em Ferramentas temos como iniciar diagnostico para fazer uma varredura das visuaçizações dos 
relatorios e a partir dessas visualizações identificamos e corrigimos oque atrapalha a integração do usuario 
---

E em Ajudas, temos varios recursos como:
- Links 
- Blogs do PowerBI 
- Tutoriais 
- Comunidade do PowerBI
